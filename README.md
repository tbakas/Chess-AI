# Chess-AI
A resnet based convolutional neural network that plays chess. The model is trained to predict the next move based on a given chess position. The transform file takes pgn files and converts them into tabular data the model can be trained with. The create model file defines the neural network. The train model file uses pytorch lightning to train the model using the transformed data. Data splits were made so that a single game cannot appear in more than one split by tracking a game_id variable. And the deploy model file can be used to play against the AI in a streamlit application. I also added logging and unit tests for the first time to one of my projects (except for the deploy model file).

For training, I downloaded pgn data for 6274 games from Magnus Carlsen's chess.com account. The model was trained on roughly 500 thousand chess positions. Its validation cross entropy loss reached a minimum of around 2.5 on epoch 3 then began to increase. So the model began overfitting quickly. And I tried playing against the model, and it's opening moves were great. But once it gets into the mid and end game portions, it tends to make blunders. This makes sense as a set of opening moves probably appears frequently in the data set, but mid and end game moves vary much more from game to game. So I believe a much larger amount of data would be needed to see high level chess from this model. Reinforcement learning or predicting engine evaluations could be used instead of predicting the next move a master-level human would make. And Alpha Zero's chess models have a second network that predicts how likely a move is to win/lose as well, so that is something that could be implemented if I return to this project.
